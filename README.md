# FM Energy Workshop

> **Workshop prototype** — this is a learning project, not a production system.

## Goal

Predict the next hour's building electricity consumption and display the
forecast on a dashboard.

Given recent consumption history (and other available signals), the project
aims to produce a one-hour-ahead forecast of building electricity demand and
surface it through an interactive dashboard for review.

## Planned tools

- **Python** — model training, data processing, and forecasting logic
- **Streamlit** — dashboard for visualizing predictions and input data
- **Neon Postgres** — managed PostgreSQL for storing consumption data and forecasts
